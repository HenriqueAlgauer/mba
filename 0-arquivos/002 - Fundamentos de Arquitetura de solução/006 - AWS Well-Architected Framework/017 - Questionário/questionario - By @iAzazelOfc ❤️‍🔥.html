Questões e Respostas

Qual das opções é um benefício do uso do AWS Well-Architected Framework?

  • Ele se concentra apenas em considerações técnicas e não considera os aspectos de negócios
  • Ele fornece uma abordagem padronizada para avaliar cargas de trabalho para melhores práticas
  • É uma solução obrigatória e aplicável a todas as cargas de trabalho.
  • Aplica-se apenas em workloads hospedados na AWS.

Qual o objetivo do pilar "Excelência operacional" no AWS Well-Architected Framework?

  • Otimizar o custo da execução de cargas de trabalho
  • Garantir que os sistemas possam ser dimensionados horizontal e verticalmente
  • Garantir que os sistemas possam se recuperar automaticamente de falhas
  • Fornecer acesso seguro e controlado a recursos e dados
  • Focar na execução e gerenciamento de sistemas para agregar valor aos negócios

Quais são os 6 pilares do AWS Well-Architected Framework?

  • Segurança, Eficiência de Desempenho, Otimização de Custos, Confiabilidade e Escalabilidade
  • Excelência operacional, Segurança, Confiabilidade, Eficiência e performance, Otimização de custos, sustentabilidade
  • Segurança, eficiência, otimização de custos, resiliência e escalabilidade
  • Segurança, desempenho, otimização de custos, confiabilidade e escalabilidade

Qual é a finalidade do pilar "Eficiência e Desempenho" no AWS Well-Architected Framework

  • Focar no uso eficiente de recursos para atender aos requisitos de carga de trabalho
  • Fornecer acesso seguro e controlado a recursos e dados
  • Garantir que os sistemas possam se recuperar automaticamente de falhas
  • Garantir que os sistemas possam ser dimensionados horizontal e verticalmente
  • Otimizar o custo da execução de cargas de trabalho

Qual das opções a seguir é um exemplo de prática recomendada pelo AWS Well-Architected Framework?

  • Armazene todos os dados em um único banco de dados para fácil acesso e gerenciamento
  • Evite usar criptografia para reduzir a sobrecarga de processamento
  • Sempre use o maior tipo de instância disponível para garantir o desempenho máximo
  • Conceda permissões amplas a todos os usuários para simplificar o gerenciamento de acesso
  • Use várias zonas de disponibilidade para garantir alta disponibilidade e tolerância a falhas

Qual é uma finalidade do pilar "Confiabilidade" no AWS Well-Architected Framework?

  • Fornecer acesso seguro e controlado a recursos e rede
  • Garantir que os sistemas possam se recuperar automaticamente de falhas
  • Garantir que os sistemas possam ser dimensionados horizontal e verticalmente
  • Fornecer acesso seguro e controlado a recursos e dados
