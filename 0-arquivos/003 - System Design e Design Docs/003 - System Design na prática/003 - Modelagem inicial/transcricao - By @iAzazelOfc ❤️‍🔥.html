Então, como a gente está imaginando assim, o ingresso está aqui, e a gente vai e chama a nossa gateway de pagamento que vai bater nesse cara, (deixa eu até trocar a cor dela para a gente conseguir registrar alguns pontos importantes). O que acontece quando a gente compra ingresso para a gente chamar a nossa gateway de pagamento? Vamos pensar o seguinte, a primeira coisa que a gente vai fazer é verificar a disponibilidade do ingresso. Depois disso, eu vou gerar uma ordem de serviço e depois eu envio a request para minha gateway. Então, esses são os primeiros passos que eu vou ter aqui na hora de eu trabalhar.
