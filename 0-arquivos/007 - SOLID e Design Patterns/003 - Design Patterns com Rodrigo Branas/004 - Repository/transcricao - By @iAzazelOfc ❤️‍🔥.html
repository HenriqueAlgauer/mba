O repository é um padrão que tem como objetivo realizar a persistência de aggregates. O que são aggregates? São clusters de objetos de domínio, como entities e value objects. Coisas que vocês estão estudando em paralelo também. Então, essa é a ideia do repository. O repository não é um padrão que persiste em qualquer coisa.
