Bom, pessoal, queria fazer algumas considerações sobre tudo isso que a gente acabou de falar. É importante você lembrar que gateways é o acesso da porta para fora. Você tem formas de acessar esses tipos de gateway, que são através de Table Gateways ou Row Gateways. “Wesley, quando eu devo usar esses caras?” Isso eu queria deixar claro para você. Eu utilizaria Table Gateway ou Row Gateway quando você tem muito CRUD. Imagina que você vai criar um ERP e, nesse ERP, você tem um monte, mas um monte mesmo, de recursos que é inserir, alterar, editar, deletar. Você tem um monte desses caras. Dependendo da situação, trabalhar com Row ou com Table Gateway faz muito sentido. O ponto importante também que eu quero deixar claro para você é que você não deve ficar escravo somente de uma forma, somente de um mecanismo de gateway. Eu posso pegar 50 CRUDs do meu sistema, que eu sei que esses caras são fixos mesmo, de utilizar Data Table Gateway. Eu posso pegar uma parte simples do meu sistema e implementar tudo isso.

Por outro lado, quando eu vou mapear o meu domínio complexo, nesse caso, eu posso utilizar um Data Mapper. Então, entenda, você não precisa ser escravo apenas de um padrão para você trabalhar na sua aplicação. Por isso é importante você entender quais são os padrões que existem, porque, assim, você vai buscar como você implementa cada padrão. E, obviamente, hoje em dia, a maioria dos seus frameworks tem todos esses padrões implementados. Então, regra número um, não fique escravo somente de um padrão. Conheça esses e mais padrões. Utilize esses padrões quando convém, combine a utilização desses padrões. Mas, o ponto principal, deixe isso de forma cada vez mais expressiva no seu software, porque é comum de você ver muitos desenvolvedores que conhecem apenas um. E o cara vai ver coisa misturada, vai falar que o seu software é uma bagunça. Mas não é uma bagunça, você utilizou o “padrão certo” para a ocasião certa, e você fez essa combinação dentro do seu software. Então se liguem nisso, porque, sim, tem muito espaço para você trabalhar com esses padrões. Não existe certo e errado, existe a situação certa para você utilizar todos eles. Maravilha? Um abraço e é isso!
