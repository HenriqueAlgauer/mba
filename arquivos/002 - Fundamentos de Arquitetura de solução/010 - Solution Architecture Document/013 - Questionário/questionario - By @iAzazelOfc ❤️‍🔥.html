  • Funcionalidades, segurança, performance
  • Recursos, disponibilidade, features de valor
  • Escalabilidade, performance, segurança

Sobre o SAD, é correto afirmar que:

  • SAD agrupa todos os dados técnicos que estarão presentes no projeto.
  • O SAD não tem validade para argumentação quando existem novas funcionalidades não acordadas, afinal ele não da clareza sobre as soluções como um todo.
  • É um documento responsável por nortear várias áreas da empresa: Técnica, comercial e gestão sobre o projeto a ser executado.
  • O SAD é desenvolvido durante a execução do projeto.

Assinale qual etapa do SAD melhor se adequa a seguinte afirmação: “Minha aplicação irá ser composta por um componente de mensageria, ela irá dispara mensagens para um tópico, ao consumir, o pagamento será processado… demonstro isso no diagrama”
